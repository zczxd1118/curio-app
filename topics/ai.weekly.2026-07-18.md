## 🌟 今日精选

### 1. Moonshot AI发布2.8万亿参数Kimi K3，开源模型首次在编程基准上超越Claude Fable 5

**[AI]** · ⭐⭐⭐⭐⭐ · _Tom's Hardware_

北京Moonshot AI今天开源了Kimi K3，2.8万亿参数，号称全球首个开放3T级系统。在Frontend Code Arena上击败了Claude Fable 5，API定价每百万token 2.3美元，创中国模型定价新高。高盛点评称中国AI公司正式从'价格战'转向'定价权'争夺。但智谱单日暴跌28%、MiniMax跌16%，显示高端编程赛道竞争白热化。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Kimi K3参数规模2.8万亿，为全球最大开源模型 | 2.8万亿参数是否真实有效，还是稀疏激活后的等效参数 |
| 在Frontend Code Arena基准上超越Claude Fable 5 | Frontend Code Arena基准的覆盖面和代表性是否足够 |
| API定价每百万token 2.3美元，为中国模型最高 | 高定价能否持续，还是短期营销策略 |
| Moonshot AI位于北京，获得多轮融资 | 开源协议的具体条款，是否真正可商用 |
| 高盛发布研报称中国AI进入定价权阶段 | 对英伟达等算力提供商的影响尚不明朗 |

**📖 主编点评**

这对你的content-curator项目是个信号：开源模型的能力天花板正在快速提升，你可以考虑用Kimi K3的API来做内容摘要或分类，成本可能比Claude更低。但注意它的编程能力更强，文本理解未必同样出色——建议先跑个benchmark对比你的使用场景。
