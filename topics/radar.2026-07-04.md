**[AI]** · ⭐⭐⭐⭐⭐ · _华尔街见闻_

字节跳动豆包与阿里通义千问同日宣布，将于7月15日下线智能体功能。这一天恰是《人工智能拟人化互动服务管理暂行办法》正式施行之日。此前上海已累计下架违规智能体1.4万余个，监管信号明确。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 豆包与通义千问确认7月15日下线智能体功能 | 其他平台（如文心一言、腾讯混元）是否会跟进 |
| 同日为《人工智能拟人化互动服务管理暂行办法》生效日 | 现有Agent开发者的迁移路径和合规成本 |
| 上海此前已下架违规智能体超1.4万个 | 监管对MCP、Function Call等底层技术的影响范围 |
| 两大平台选择同日下线，非巧合 | 海外AI Agent产品（如Claude Code）在中国市场的合规风险 |
|  | 智能体功能下线后，用户数据与已部署Agent的处理方案 |

**📖 主编点评**

如果你在用豆包或千问构建Agent，7月15日前需要完成数据导出和方案迁移。建议关注合规的私有化部署方案，或转向海外API。这个事件也意味着国内AI Agent的商业模式可能从C端智能体转向B端工具链——你的content-curator项目如果依赖国内平台，需要提前评估风险。

### 2. 三星2nm代工订单积压50万亿韩元，Meta、Anthropic相继转向

**[半导体]** · ⭐⭐⭐⭐⭐ · _华尔街见闻_

三星电子凭借2nm制程工艺，在AI芯片代工市场快速崛起。继特斯拉之后，Meta与Anthropic也选择三星作为代工伙伴。目前中长期订单积压已近50万亿韩元，代工业务最早有望今年四季度扭亏为盈。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 三星2nm制程获得Meta、Anthropic代工订单 | 三星2nm良率与台积电的差距是否已缩小 |
| 此前特斯拉已转向三星 | Anthropic自研芯片的具体规格与量产时间 |
| 中长期订单积压近50万亿韩元（约合380亿美元） | 三星代工扭亏时间表是否可信 |
| 三星存储+代工+封装一体化能力是关键优势 | 对台积电CoPoS等先进封装技术的影响 |

**📖 主编点评**

### 4. 美国最大电网触发二级紧急警报，北弗吉尼亚数据中心电价飙至2500美元/MWh

**[半导体]** · ⭐⭐⭐⭐ · _华尔街见闻_

PJM电网在极端高温与AI算力扩张双重压力下，触发二级能源紧急警报。全球最大数据中心集群所在地北弗吉尼亚，现货电价从平时的40美元/MWh飙升至2500美元/MWh以上，涨幅超60倍。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| PJM电网7月2日触发二级能源紧急警报 | 数据中心扩张与电网容量之间的结构性矛盾将持续多久 |
| 北弗吉尼亚现货电价突破2500美元/MWh | 核电/小型模块化反应堆能否及时填补缺口 |
| 平时电价约40美元/MWh | 电价飙升是否会倒逼AI公司优化推理效率 |
| 能源部下令所有机组满负荷运行 | 对AI云服务定价的传导效应 |

**📖 主编点评**

电价飙升直接推高AI推理成本。如果你在用云API做Agent项目，未来几个月可能看到服务涨价或配额收紧。建议关注能效优化技术（如量化、稀疏化）和边缘计算方案，这些会成为成本竞争力关键。
