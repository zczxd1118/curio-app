**[大厂 AI 动态]** · ⭐⭐⭐⭐ · _ilreb_

DeepMind 在 Gemini 4 系列密集发布（Carbon、Hydrogen、Omni 1.2 Flash、Decisions API）之间，插了一个 AlphaProof Code。名字说明一切：AlphaProof 是把数学证明形式化的系统，加 Code 意味着它开始处理可验证的代码正确性，而不是"看起来能跑"。这是本周唯一一条不涉及人事和股价的硬技术发布。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| DeepMind 官方博客发布 AlphaProof Code | AlphaProof Code 是产品还是研究预览，博客未明确 |
| HN 679 分，是本周技术类最高分条目 | 形式化验证的覆盖范围（是否只支持特定语言/框架）未知 |
| 同期 Gemini 4 Carbon 在 Artificial Analysis Intelligence Index v5 上排名第一 | 对日常 vibe coding 的可用性：短期内大概率不面向普通开发者 |
| Gemini 4 Hydrogen 与 Orchestrator 已在 Google Antigravity 中上线 | 与 Claude Code、Cursor 的定位是否重叠，目前看是互补而非竞争 |

**📖 主编点评**
