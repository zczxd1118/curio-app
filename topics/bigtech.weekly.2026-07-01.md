## 🌟 今日精选

### 1. Anthropic 的 Fable 5 解禁回归，同时推出 Sonnet 5 和 Claude Science

**[大厂 AI 动态]** · ⭐⭐⭐⭐⭐ · _The Verge_

经过数周与特朗普政府谈判，Anthropic 的旗舰模型 Fable 5 获准恢复上线。同一天，公司还发布了更便宜的 Claude Sonnet 5（主打 Agent 能力）和面向科研的 Claude Science 工作台。三管齐下，Anthropic 正在从单一模型公司转向平台生态。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Fable 5 将于本周开始逐步恢复访问，此前因监管限制被下线数周 | Fable 5 恢复后是否会调整安全策略尚不明确 |
| Claude Sonnet 5 发布，定价低于 Opus，强化 Agent 调用能力 | Sonnet 5 的 Agent 能力在实际复杂任务中能否媲美 Opus 有待验证 |
| Claude Science 是一个集成环境，整合数据库、计算管道和工具链 | Claude Science 能否真正替代科研人员现有的 Jupyter/Colab 工作流存疑 |
| Sonnet 5 定位为 GPT-5.5 和 Gemini Pro 的廉价替代方案 | Anthropic 的产品线扩张速度可能超过企业客户的采纳节奏 |

**📖 主编点评**

如果你在用 Claude Code 做 Agent 项目，Sonnet 5 的性价比值得立即测试——更低的 token 成本意味着你可以跑更多实验。Claude Science 对科研场景的整合思路也值得借鉴到你的 content-curator 项目中：把多个工具链塞进一个统一环境。
