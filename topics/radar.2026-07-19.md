## 🌟 AI

### 1. Moonshot AI 发布 2.8 万亿参数 Kimi K3，开源模型首次在编程基准上超越 Claude Fable 5

**[AI]** · ⭐⭐⭐⭐⭐ · _Tom's Hardware_

Moonshot AI 于 7 月 17 日发布 Kimi K3，2.8 万亿参数、100 万 token 上下文，在 Frontend Code Arena 上超越 Claude Fable 5 和 GPT-5.6。这是中国公司绕开美国算力限制后交出的最大开源模型，API 定价 2.3 美元/百万 token，创国内新高。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Kimi K3 拥有 2.8 万亿参数，100 万 token 上下文窗口 | 2.8T 参数是否带来推理成本过高，实际部署性价比存疑 |
| 在 Frontend Code Arena 编程基准上超越 Claude Fable 5 和 GPT-5.6 | 编程基准领先能否泛化到其他复杂任务（如数学、推理） |
| API 定价每百万 token 2.3 美元，为国内模型最高定价 | 高定价策略能否持续，还是短期营销手段 |
| Moonshot AI 称其为“世界首个开放 3T 级系统” | 开源程度：是否完全开放权重，还是部分开源 |
| 已可接入 Claude Code 等工具使用 | 对国内其他模型（DeepSeek、智谱）的竞争压力评估 |

**📖 主编点评**

如果你在做 Agent 或编程工具，Kimi K3 值得立刻接入测试。2.8T 参数意味着更强的代码理解和生成能力，尤其适合复杂多文件项目。但注意 API 成本，建议先用小量测试对比 Claude Fable 5 和 GPT-5.6 在你的具体场景下的表现。同时关注 DeepSeek V4 明天发布后的定价策略，可能引发新一轮价格战。

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐ · _Tom's Hardware_

TSMC 在 7 月 17 日更新中表示，其 A14（1.4nm）工艺进展快于同期 N2，良率和性能提升显著。AI/HPC 和智能手机客户表现出强烈兴趣。同时 TSMC 将 2026 年资本预算提高至 640 亿美元，并追加 1000 亿美元美国投资。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| A14 工艺良率和性能提升显著，进展快于 N2 同期 | A14 量产时间表是否提前（原计划 2028 年） |
| AI/HPC 和智能手机客户均表现出强烈兴趣 | ASML 涨价对 TSMC 毛利率的影响程度 |
| 2026 年资本预算提高至 640 亿美元 | 美国工厂能否按时投产并达到良率目标 |
| 追加 1000 亿美元美国投资 | 英特尔 Nova Lake 采用外部代工是否分流订单 |
| ASML 计划提高 Low-NA EUV 价格，可能增加 TSMC 成本 |  |

**📖 主编点评**

A14 的快速进展意味着 2028 年前后你将看到更强大的 AI 芯片。对于做 AI 推理优化，这意味着更低的每 token 成本和更高的能效。但注意 ASML 涨价可能推高芯片成本，最终转嫁给云服务用户。建议关注 TSMC 下周法说会上的具体时间表。
