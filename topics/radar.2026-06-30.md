### 1. 韩国800万亿韩元存储扩产计划：三星、SK海力士新建4座晶圆厂，HBM产能翻倍

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐⭐ · _Tom's Hardware_

韩国总统李在明宣布史上最大半导体投资计划，三星与SK海力士将在西南地区新建4座晶圆厂和HBM专用设施，总投资800万亿韩元（约5200亿美元）。该计划是此前美国CHIPS法案的10倍规模，目标是在2028年前实现HBM产能翻倍，并抢占物理AI时代存储制高点。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 韩国政府宣布在西南地区新建存储芯片集群，包括4座晶圆厂 | 新产能最早需8-10年才能实质影响全球供给，短期供需格局不变 |
| 三星披露2450万亿韩元国内长期投资计划 | HBM产能扩张速度受制于先进封装良率，实际产出可能低于规划 |
| SK海力士同步扩建HBM专用产线 | 中国存储厂商（如CXMT）扩产进度可能加速，加剧竞争 |
| 全球存储资本开支2026/2027年预计达1103亿/1685亿美元，同比增长63%/53% | DRAM价格已处历史高位，扩产周期可能引发价格拐点 |
|  | 韩国政府补贴力度和实际执行效率待观察 |

**📖 主编点评**

这对你意味着：存储芯片的超级周期已经确认，但短期不会缓解内存涨价压力。如果你在做AI推理部署，建议提前锁定DDR5/HBM合同；如果你是投资者，关注设备商（如ASML、东京电子）和材料商（如信越化学）的订单弹性。

### 2. Anthropic与加州政府达成协议：Claude以半价进入政府场景

**[大厂 AI 动态]** · ⭐⭐⭐⭐⭐ · _TechCrunch_

Anthropic与加州州长纽森达成协议，为加州政府机构提供Claude API半价折扣。这是AI公司首次大规模进入美国州政府场景，标志着AI在公共服务领域的商业化落地加速。与此同时，联邦政府正对Anthropic展开反垄断调查，形成鲜明对比。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 加州政府机构可使用Claude API，价格为标准定价的50% | 半价策略可能引发其他AI公司跟进，形成政府市场价格战 |
| 协议覆盖多个政府部门，包括交通、医疗、教育等 | 政府场景的数据隐私和合规要求可能限制Claude的应用范围 |
| Anthropic将提供定制化安全审查和合规支持 | 联邦与州政府态度分歧可能影响Anthropic的IPO估值 |
| 联邦政府同期对Anthropic启动反垄断调查 | 该协议可能成为其他州政府效仿的模板 |

**📖 主编点评**

这对你意味着：如果你在做政府或公共服务类AI产品，这是重要的市场信号——政府客户对AI的接受度正在提高，但价格敏感度极高。建议关注Anthropic的定价策略变化，以及后续其他厂商的跟进动作。

### 3. Cursor推出移动端App：远程监督AI编程Agent

**[大厂 AI 动态]** · ⭐⭐⭐⭐ · _TechCrunch_

Cursor正式发布移动端App，允许开发者通过手机远程监督和指导AI编程Agent。用户可以在移动端查看代码变更、提交修改建议、启动/暂停任务。这是AI编程工具从IDE向全场景延伸的关键一步，也反映出AI编程Agent正从辅助工具向自主开发角色演进。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Cursor移动App支持iOS和Android | 移动端App的代码编辑能力有限，主要面向监督而非开发 |
| 核心功能包括：查看代码变更、提交修改建议、启动/暂停Agent任务 | 远程Agent管理可能带来安全风险，需关注权限控制 |
| 支持与桌面端Cursor实时同步 | 该功能可能推动AI编程工具从开发者工具向平台化演进 |
| 免费用户可使用基础功能，Pro用户可管理多个Agent | 竞争对手（如Claude Code、Codex）可能快速跟进 |

**📖 主编点评**

这对你意味着：如果你在用Cursor做Side Project，现在可以在通勤时远程监督Agent干活了。建议尝试将重复性任务（如bug修复、测试编写）委托给Agent，利用移动端碎片时间管理。但注意不要完全信任Agent，关键决策仍需人工确认。

## 🌟 AI

### 4. Mozilla 0din团队演示：AI编程Agent可被恶意GitHub仓库诱导安装恶意软件

**[AI]** · ⭐⭐⭐⭐ · _Tom's Hardware_

Mozilla的0din安全团队发布PoC，展示如何通过一个看似干净的GitHub仓库诱导Claude Code等AI编程Agent安装恶意软件。攻击者只需在仓库中嵌入隐蔽的恶意代码，当Agent执行初始化项目等操作时，就会被触发下载并执行恶意负载。这暴露了AI编程Agent在供应链安全方面的重大隐患。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Mozilla 0din团队成功诱导Claude Code安装恶意软件 | 该攻击需要用户主动让Agent操作恶意仓库，实际利用门槛较高 |
| 攻击向量：在GitHub仓库中嵌入隐蔽恶意代码 | AI编程工具厂商可能需引入仓库安全扫描机制 |
| 触发条件：Agent执行项目初始化、依赖安装等常见操作 | 用户应避免让Agent操作未经验证的第三方仓库 |
| 该漏洞影响所有基于LLM的编程Agent，包括Cursor、Codex等 | 该问题可能推动AI编程工具的安全审计功能标准化 |

**📖 主编点评**

这对你意味着：如果你在用Claude Code或Cursor开发项目，务必注意仓库来源。建议在沙箱环境中运行Agent，或使用Docker等隔离机制。同时，关注各工具厂商的安全更新，及时升级到最新版本。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 韩国投资者通过杠杆ETF和TRS大量做多科技股 | 融资成本持续上升可能触发强制平仓，引发连锁反应 |
| 标普500指数总收益期货融资利率升至历史高位 | 韩国散户的杠杆行为具有高度情绪化特征，难以预测 |

| KOSPI指数呈现自我强化的反馈回路 | 监管机构可能出台限制杠杆措施，但时机不确定 |

**📖 主编点评**

这对你意味着：如果你持有科技股或相关ETF，建议关注韩国市场的杠杆指标。高盛的警告信号不容忽视，可以考虑适当降低杠杆仓位，或配置对冲工具。对于个人投资者，避免追高已过度杠杆化的标的。
