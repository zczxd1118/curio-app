### 3. DeepSeek 完成首轮 500 亿融资：梁文锋个人出资 200 亿，腾讯宁德时代跟投

**[AI]** · ⭐⭐⭐⭐⭐ · _华尔街见闻_

DeepSeek 宣布完成首轮外部融资，总额超 500 亿元人民币，估值超 3300 亿元。创始人梁文锋个人出资 200 亿元，为最大投资方；腾讯、宁德时代、京东、网易及 IDG 资本等跟投。为确保梁文锋绝对控制权，外部投资者资金须注入由其管理的有限合伙企业，股份锁定期五年。国家人工智能产业投资基金为唯一例外，直接注资 10 亿元并享有投票权。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| DeepSeek 首轮融资超 500 亿元，估值超 3300 亿元 | DeepSeek 的估值对标 OpenAI（7300 亿美元）仍有空间，但中国 AI 市场估值体系不同 |
| 梁文锋个人出资 200 亿元，保持绝对控制权 | 梁文锋的绝对控制权设计可能影响后续融资灵活性 |
| 腾讯、宁德时代、京东、网易、IDG 资本等参投 | 腾讯等战略投资者的加入意味着 DeepSeek 将深度整合进入中国互联网生态 |
| 外部投资者资金注入有限合伙企业，锁定期五年 | 融资后 DeepSeek 可能加速发布新一代模型，与 Claude 和 GPT 竞争 |
| 国家 AI 产业基金直接注资 10 亿元，享有投票权 | 国家基金的参与暗示 DeepSeek 将承担部分国家 AI 基础设施角色 |

**📖 主编点评**

这对你的 Agent 项目是利好：DeepSeek 的 API 价格通常低于海外竞品，且国内访问稳定。如果 Anthropic 的模型被限制，DeepSeek V4 是 Claude Code 的最佳替代方案（已有社区教程）。建议立即测试 DeepSeek V4 + Claude Code 的集成方案，作为你 content-curator 项目的底层模型备选。
