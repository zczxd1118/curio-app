### 3. Google 发布 Gemini 4 Neon，登顶 Models Engineering Index，被指对标 Opus 5.5

**[大厂 AI 动态]** · ⭐⭐⭐⭐ · _yigitdemirag_

Gemini 4 系列在两个月内连发 Carbon、Hydrogen、Neon 三个版本，Neon 是最新一版，发布当天即登上 Models Engineering Index 第一。社区评测普遍把它和 Opus 5.5 放在同一档比较。对做 Agent 的人来说，真正值得看的是 Neon 在 Antigravity 里的 Orchestrator 集成——那是 Google 对「多 Agent 编排」的官方答案。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Gemini 4 Neon 已在 Google 官方博客发布，同日上线 | Neon 相对 Opus 5.5 的实际差距，目前只有社区评测，缺独立第三方基准 |
| Neon 登上 Models Engineering Index 第一 | Orchestrator 的多 Agent 编排能力是否开放给个人开发者，定价未明 |
| Gemini 4 系列在约一个月内连续发布 Carbon、Hydrogen、Neon 三个版本 | 一个月三版是否意味着模型迭代已进入「快消」节奏，长期稳定性存疑 |
| Google 同步在 Antigravity 平台提供 Gemini 4 Hydrogen + Orchestrator 集成 |  |
| Gemini 4 Carbon 此前曾在 Artificial Analysis Intelligence Index v5 登顶 |  |

**📖 主编点评**

你正在做 Agent 项目，Neon + Orchestrator 是这周最值得动手试的组合：拿你 content-curator 的选稿流程做一个多 Agent 编排的对照实验，看 Google 官方方案和你现在的单 Agent 实现差在哪。这比读十篇评测有用。
