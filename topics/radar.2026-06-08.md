### 5. S&P 拒绝为SpaceX等超级IPO修改快速纳入规则，指数基金被动配置承压

**[股票]** · ⭐⭐⭐⭐ · _Bloomberg_

S&P Dow Jones 在咨询后决定维持现有指数纳入规则，拒绝为SpaceX、Anthropic等超级IPO提供快速通道。这意味着即使这些公司上市后市值巨大，也必须等待至少12个月才能被纳入S&P 500等主流指数。此举将迫使指数基金在IPO后通过主动交易来追踪，增加了跟踪误差和成本。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| S&P Dow Jones 于6月4日宣布维持现有指数纳入规则 | SpaceX IPO定价和上市时间尚未最终确定，路演仍在进行 |
| SpaceX 估值目标1.77万亿美元，Anthropic 估值超600亿美元 | Fidelity已将SpaceX IPO最低投资额从50万美元降至2000美元，散户参与度可能提升 |
| 现有规则要求公司至少上市12个月才能被纳入S&P 500 | 若SpaceX上市后股价大幅波动，指数基金可能面临较大的跟踪误差 |
| Bloomberg报道称，此举将增加指数基金的跟踪成本和交易复杂度 | 长期看，S&P可能在未来重新评估规则，但短期内不会改变 |

**📖 主编点评**

如果你计划参与SpaceX或Anthropic的IPO，注意它们不会很快进入指数，意味着主动选股而非被动配置。对于你的content-curator项目，这是一个值得追踪的金融事件——IPO动态和指数规则变化会影响科技股的整体流动性。建议关注SpaceX路演进展和最终定价。

### 2. Claude Code 推出「超码」Ultracode：操控100个Agent并行开发，解决大型任务跑不完的痛点

**[AI]** · ⭐⭐⭐⭐⭐ · _技术胖_

Anthropic 在 Claude Code 中上线了 Ultracode 功能，允许用户同时调度最多100个Agent并行执行任务。这解决了Claude Code此前一次性跑不完大型项目的核心痛点——现在你可以拆解任务、并行开发、自动协调。技术胖的保姆级教程展示了从安装到实战的完整流程，包含具体命令和配置。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Ultracode 是 Claude Code 的新功能，支持最多100个Agent并行工作 | 100个Agent并行是否会产生协调开销和token浪费，需实测验证 |
| 功能于2026年6月4日上线，技术胖在6月5日发布实战教程 | 该功能是否仅限Claude Code Pro用户，定价策略尚未明确 |
| 教程包含具体安装步骤、任务拆分策略、Agent协调配置 | 与GitHub Copilot App、Cursor等竞品的多Agent能力对比尚缺 |
| Ultracode 解决了 Claude Code 此前大型任务超时或上下文溢出问题 | 实际工程中能否稳定运行100个Agent，取决于任务类型和API稳定性 |

**📖 主编点评**

这对你的 content-curator 项目是直接利好——可以用 Ultracode 并行爬取、清洗、分类多个信息源，大幅缩短开发周期。建议今晚就跟着技术胖的视频搭环境，从拆分你的Agent任务开始试水。注意控制并行度，先跑10个Agent测试稳定性。

## 🌟 大厂 AI 动态

### 4. OpenAI 推出 Lockdown Mode：防止提示注入攻击，保护敏感数据

**[大厂 AI 动态]** · ⭐⭐⭐⭐ · _TechCrunch_

OpenAI 发布了 Lockdown Mode，一项旨在防止提示注入攻击的新安全功能。该模式限制ChatGPT在对话中共享敏感数据，即使攻击者试图通过恶意提示绕过限制。这是OpenAI在安全方面的重要一步，尤其适合企业级部署。不过TechCrunch指出，Lockdown Mode并不能完全免疫所有提示注入攻击。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| OpenAI 于6月6日发布 Lockdown Mode | Lockdown Mode 的具体实现机制（基于规则还是模型微调）未公开 |
| 该模式旨在防止提示注入攻击导致敏感数据泄露 | 该功能是否适用于API调用，还是仅限ChatGPT界面 |
| Lockdown Mode 会限制模型在对话中输出特定类型的信息 | 与Anthropic的Constitutional AI等安全方案相比效果如何 |
| OpenAI 承认该模式不能完全消除提示注入风险 | 企业用户是否愿意为安全功能支付溢价 |

**📖 主编点评**

如果你正在用AI Agent处理用户数据或内部文档，Lockdown Mode 是一个必须关注的安全更新。建议在 content-curator 项目中集成该模式，防止用户通过恶意提示窃取你的爬虫配置或API密钥。同时注意，它并非银弹，仍需配合输入验证和权限控制。

📺 [打开原文](https://techcrunch.com/2026/06/06/openai-unveils-lockdown-mode-to-protect-sensitive-data-from-prompt-injection-attacks/)
