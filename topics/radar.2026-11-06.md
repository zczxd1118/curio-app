## 🌟 大厂 AI 动态

### 2. Ben Thompson：数据中心上了选票，而且大败——如果美国人对「建设」的反对是永久性的，AI 扩张的天花板在哪

**[大厂 AI 动态]** · ⭐⭐⭐⭐⭐ · _Ben Thompson_

Stratechery 把中期选举结果读成一个结构性问题：美国地方政治对大型基建的否决能力正在系统性增强，而 AI 数据中心恰好是最需要土地、电力和社区许可的那类基建。文章的核心追问不是「这次跌多少」，而是「如果反对建设是长期状态，AI 的物理扩张靠什么完成」。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 中期选举中多个县将数据中心议题列入公投 | 「永久性反对建设」是否成立，还需要看后续州级立法走向 |
| 多数选民投票反对本县的数据中心开发 | AI 基建是否会因此加速向海外（中东、东南亚）转移，尚无数据 |
| Ben Thompson 判断这是对 AI 基建扩张的结构性约束 | 地方否决能否被联邦层面的许可改革对冲，目前只是讨论阶段 |
| 同期 Meta、OpenAI 均公开承认社区反对可能拖慢扩张 | 对模型能力进展的实际拖累幅度，可能要到 2027 年才显现 |

**📖 主编点评**

这是今天最值得花 15 分钟读完的一篇。你平时关注的是 Agent 工具链，但这条提醒你：上游算力的物理约束会以「API 变贵、限流变严、区域可用性下降」的形式传导到你手上。建议你把「供应商算力风险」加进 content-curator 的长期架构考虑里，比如保留多模型切换能力。

### 4. DeepSeek Harness 开源 Super-agent 实测：和传统 Agent 差在哪，插件化工具链是不是真能提升效率

**[AI]** · ⭐⭐⭐⭐ · _程序员鱼皮_

DeepSeek Harness 团队开源的 Super-agent 在中文社区已经跑出一批实测。这条视频的价值是它没有停在「是什么」，而是拿同一个模型在 Claude Code 和 DSH 里跑相同任务，对比工具链对最终产出的影响——这正是你关心的「模型之外的那一半」。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| DeepSeek Harness 团队开源了 Super-agent 项目 | 「工具链比模型更重要」这个结论目前只有小样本实测支撑 |
| 社区已有多个实测视频对比 DSH 与 Claude Code 的同任务表现 | DSH 的插件生态成熟度与 Claude Code 差距多大，尚无系统对比 |
| DSH 采用插件化架构，强调流程记录与缓存命中 | 开源协议与商用限制细节未在视频中展开 |
| 实测覆盖游戏 Demo、动画、源码流程等多类任务 | 长期维护是否跟得上，取决于 DeepSeek 团队投入 |

**📖 主编点评**

你正在做 content-curator，这条值得看的是「插件化 + 流程记录」这套设计思路，而不是照抄 DSH。建议你重点看它怎么记录 Agent 的中间步骤——这对你调试自己的子 Agent 编排会直接有用。看完可以拿你的项目跑一次同任务对比，成本很低。

### 5. Marvell 以 1150 亿美元全股票收购 Lumentum，押注 AI 数据中心的 scale-up 与 scale-in 光互连

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐ · _Etiido Uko_

在 AI 股票普跌的同一天，Marvell 宣布用 1150 亿美元全股票吞下 Lumentum，把光 DSP、SerDes、硅光与激光器、光开关、InP 材料整合到一家公司。这是今年半导体领域最大的一笔并购，赌的是「算力瓶颈会从芯片转向互连」。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 交易为 1150 亿美元全股票收购 | 全股票交易在股价下跌期完成，实际对价可能缩水 |
| 合并后覆盖光 DSP、SerDes、硅光、激光器、光开关、InP 材料 | 监管审批风险尚未评估，光器件领域集中度会显著上升 |
| 目标场景明确指向 AI 数据中心的 scale-up 与 scale-in 光互连 | 「互连成为瓶颈」的判断是否被产业验证，还需要看 2027 年部署 |
| 交易宣布时点正值 AI 相关股票大幅回调 | 整合风险：两家公司产品线重叠度与裁员规模未知 |

**📖 主编点评**

这条对你不是投资建议，而是技术方向的提示：AI 算力的瓶颈正在从「算得多快」转向「数据搬得多快」。如果你以后碰推理优化或部署，光互连、NVLink 这类词会越来越常出现在工程文档里，值得提前建立基本概念。
