|---|---|

| 募资规模超 $800 亿，估值约 $1.5T | Blackstone 等机构此前质疑其难拿投资级评级，信用评级结果尚未落地 |

你不需要买这只票，但要看懂它的结构：招股书里的 $9000 亿算力承诺和 $1560 亿公益承诺，是理解"AI 公司如何用未来现金流换今天估值"的最好教材。建议你花 20 分钟读一遍招股书里 compute commitments 那一节，比任何二手解读都值。

### 3. Gemini 拿到 Mac 控制权：能整理文件、填表单、跑多步工作流，桌面 Agent 战开打

**[大厂 AI 动态]** · ⭐⭐⭐⭐ · _TechCrunch_

Google 给 Gemini 加了 Mac 端 Agent 能力，可以操作文件、填表单、执行多步骤工作流。同一周 Apple 被曝在招人自建 AI Agent，Meta 的 Muse Charm 定价 $300 曝光。桌面/设备级 Agent 从"聊天框"走向"替你操作电脑"，这是 2026 下半年最明确的产品方向。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Gemini 更新后可在 Mac 上整理文件、填表单、执行多步工作流 | 桌面 Agent 的权限边界与隐私风险，Google 尚未给出完整说明 |
| Apple 发布招聘信息，组建自建 AI Agent 团队，覆盖浏览网页、跨 App 操作、写代码 | Apple 的 Agent 仍在招聘阶段，落地时间未知 |
| Meta Muse Charm 设备据 The Information 报道定价 $300 | Meta Muse 此前被曝混淆对话、可能泄露隐私数据，设备级 Agent 的可靠性仍是问号 |
| Gemini 4 Neon 登上 Models Engineering Index 第一 |  |

**📖 主编点评**

你的 content-curator 本质就是一个跑在个人设备上的 Agent，Gemini 这波"操作 Mac"的能力值得你拆解它的工具调用设计——尤其是它怎么处理多步工作流的中间状态和失败回滚。这正好是你项目里最缺的那块工程细节。

### 2. Nvidia 临时 CEO 交出 $115.8B 季度营收，业绩没塌但治理真空叠加走私与新加坡停披露

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐⭐ · _EE Times_

黄仁勋因丑闻辞职后，临时 CEO Colette Kress 主持了首个财报：季度营收 $115.8B，AI 基础设施需求仍在托底。但同期公司停止披露新加坡销售额、高管家属卷入芯片走私案、董事在丑闻前抛售近 $10 亿股票，治理层面的裂缝比业绩更值得盯。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 临时 CEO Colette Kress 主持财报，季度营收 $115.8B | $115.8B 是否可持续，取决于下季度 AI 资本开支是否放缓 |
| AI 基础设施需求仍是营收主引擎，利润维持 | 新加坡销售停披露是否与 Megaspeed 相关的转口贸易有关，尚无定论 |
| 公司已停止披露新加坡地区销售额 | 董事会明确表示不打算让黄仁勋回归，但员工请愿要求其回归，内部张力未解 |
| 一名高级副总裁的妻子被卷入 AI 芯片走私案 | Arm CEO Rene Haas 被接触接任，最终人选未定 |
| 一名董事在丑闻曝光前数周抛售近 $10 亿股票 |  |

**📖 主编点评**

如果你在做 AI 产品，短期不用慌——算力供给和价格没变。但要开始关注"治理风险如何传导到供应链"：出口管制收紧、转口贸易被查，都可能让某些型号的交付周期变长。给你的 Agent 项目留一条备用推理通道（比如本地小模型兜底）是低成本保险。

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐ · _Tom's Hardware_

OpenAI 用模型参与 AMD 下一代旗舰 GPU 的设计优化，PPA（性能/功耗/面积）提升 14%，同样的方法也用在了新 CPU 上。这是"AI 设计芯片"从论文走进真实产品线的标志性案例——不是概念演示，是进了流片前的设计流程。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| OpenAI 协助 AMD 优化下一代旗舰 GPU 设计，PPA 提升 14% | 14% PPA 提升的具体测试条件与可复现性未公开 |

## 🌟 金融

### 5. Visa、Mastercard、JPMorgan 客户数据被黑客泄露，支付链核心同时中招

**[金融]** · ⭐⭐⭐⭐ · _WSJ / Hacker News_

WSJ 报道 Visa、Mastercard 与 JPMorgan 的客户数据被黑客泄露。三家同时中招，指向的可能不是各自系统被攻破，而是共享的第三方环节出问题。同一周美国国家网络总监宣布离职、多地出现原因不明的技术故障，支付与基础设施安全进入一个不太平的窗口。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Visa、Mastercard、JPMorgan 客户数据被黑客泄露 | 泄露源头是共享第三方还是各自系统，尚未披露 |
| 泄露由 WSJ 报道，三家公司均属支付/银行核心环节 | 是否与近期 AI Agent 相关的基础设施故障有关，目前只是猜测 |
| 同期美国国家网络总监宣布辞职 | 受影响客户规模与数据类型未明 |
| 美国多地企业报告一批原因不明的技术故障 |  |

**📖 主编点评**

这条和你的项目直接相关：你的 Agent 会接触 API key、账号凭证、抓取的数据。趁这次事件把个人项目的密钥管理过一遍——别把 key 硬编码进仓库，用环境变量 + 定期轮换，这是简历上"工程规范"最容易被问到的一点。

📺 [打开原文](https://www.wsj.com/finance/banking/visa-mastercard-and-jpmorgan-customer-data-leaked-by-hackers-3b5a0f87)
