**[大厂 AI 动态]** · ⭐⭐⭐⭐⭐ · _TechCrunch_

6 月 12 日，白宫以“安全护栏可被绕过”为由，要求 Anthropic 立即封锁 Claude Fable 5 及 Mythos 系列模型的海外访问。Anthropic 被迫执行，CEO Dario Amodei 此前曾拒绝修复政府报告的 jailbreak 漏洞。这不仅是技术安全争议，更是特朗普政府对 AI 出口管制的极端化——将商业模型视为“武器级技术”。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 美国商务部要求 Anthropic 阻止 Fable 5 和 Mythos 模型被中国等国家访问 | 禁令的真实动机是地缘政治而非安全：政府可能借机施压 Anthropic 配合更广泛的 AI 管控 |
| Anthropic 已按要求下线模型，高管正赴白宫谈判重新上线条件 | Fable 5 的 jailbreak 严重程度被夸大：Anthropic 内部认为漏洞属于“低风险” |
| 政府援引出口管制法规，将 AI 模型类比为“国防技术” | 重新上线的条件可能包括强制加入政府后门或审查机制 |

**📖 主编点评**

这对你的 content-curator 项目是个警示：AI 工具链的可用性正变得政治化。如果你依赖 Claude Code 或海外 API 构建 Agent，建议提前储备本地模型（如 DeepSeek）作为备选。同时关注 Anthropic 谈判结果——若 Fable 5 永久受限，Claude Code 的能力上限将被锁定在当前版本。

## 🌟 AI 算力 / 半导体

### 4. AMD 与苹果押注闪存替代 DRAM：AI 存储成本或降 55 倍

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐ · _华尔街见闻_

面对 DRAM 价格暴涨，AMD 收购内存优化公司 MEXT，将 AI 驱动闪存技术引入数据中心；苹果同步推进端侧闪存方案。两家巨头看重闪存成本仅为 DRAM 的 1/55，正重构 AI 存储架构。AMD 的 Predictive Memory Engine 可将不常访问的数据从 DRAM 卸载至 NAND，对应用透明。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| AMD 收购 MEXT，获得 Predictive Memory Engine 技术 | 闪存替代 DRAM 在推理场景效果显著，但训练场景仍需高带宽内存 |
| 该技术可将闪存虚拟化为 DRAM，对应用透明 | AMD 的技术可能率先用于云数据中心，消费级产品需 1-2 年 |
| 闪存成本约为 DRAM 的 1/55 | 苹果的端侧方案将提升 iPhone/iPad 上的本地 AI 推理能力 |
| 苹果也在推进端侧闪存方案 | 长期看，存储架构变革将降低 AI 推理的总体拥有成本 |
| DRAM 价格因 AI 需求暴涨，数据中心存储成本承压 | Nvidia 可能推出类似技术以保持生态竞争力 |

**📖 主编点评**

如果你在本地运行 AI 模型（如通过 Ollama 或 LM Studio），未来 Mac 或 PC 可能通过闪存扩展可用内存，让你运行更大的模型。对于 content-curator 项目，这意味着你可以在本地部署更强的开源模型，减少 API 依赖。关注 AMD 的消费级实现时间线。
