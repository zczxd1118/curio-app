## 🌟 今日精选

### 1. Nvidia 董事会拒绝 Huang 回归，临时 CEO 宣布退出中国市场，SEC 同步立案

**[AI 算力 / 半导体]** · ⭐⭐⭐⭐⭐ · _mfiguiere_

Q3 财报电话会上，新任董事长 Harvey Jones 开场就定调：董事会一致接受辞呈，不打算让 Jensen Huang 回来。临时 CEO Colette Kress 同日表示公司不再向中国卖芯片。财报本身仍是创纪录季度，但叙事重心已经从增长转向治理与合规。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 董事会主席 Harvey Jones 在财报电话会明确表示不打算恢复 Huang 的 CEO 职务 | 退出中国市场对营收的实际冲击尚未量化，Kress 只说"代价待评估" |
| 临时 CEO Colette Kress 表示 Nvidia 已停止向中国销售芯片 | 650 亿美元投资组合在失去 Huang 后能否维持交易节奏，目前无公开计划 |
| WSJ 报道 SEC 已就 Huang 离职相关事宜对 Nvidia 展开调查 | SEC 调查范围是否涉及信息披露而非个人行为，尚无细节 |
| Huang 本人发表离职后首次公开声明，称若被允许回归将感到荣幸 | 董事会是否已有接任人选，Arm 的 Rene Haas 被接触一事未获证实 |
| Nvidia 持有初创公司股权价值九个月内接近翻三倍，达约 650 亿美元 | 员工联名要求复职的内部信是否会影响董事会决策，概率偏低 |
| Huang 将于 12 月 1 日就涉中国间谍疑云赴众议院外交事务委员会闭门作证 |  |

**📖 主编点评**

你不需要关心八卦，但需要关心两件事：一是 Nvidia 退出中国后，国内算力供给和国产替代的节奏会加速，如果你在做的 Agent 项目依赖云端推理，留意后续 API 价格与可用性变化；二是 650 亿美元的投资组合若收缩，一批靠 Nvidia 战投续命的 AI 初创会先出问题。Stratechery 今天的分析值得读，Ben Thompson 认为财报"无聊"本身就是 Huang 回不来的理由。
