## 🌟 今日精选

### 3. OpenAI CFO 全员会表态：Q3 ARR 增 35%，2027 年或更早上市，但人才流失成隐患

**[大厂 AI 动态]** · ⭐⭐⭐⭐⭐ · _华尔街见闻_

面对 Q2 收入增速仅 18%、高管接连出走的压力，OpenAI CFO 在全员会上亮出 Q3 最新数据：整体 ARR 至今增长 35%，企业 ARR 增长 50%，并明确表示公司“将在 2027 年或更早上市”。此前有报道称 OpenAI 已解散评估灾难性模型风险的团队，引发外界对其安全治理的担忧。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| OpenAI CFO 在全员会上表示 Q3 整体 ARR 增长 35%，企业 ARR 增长 50%。 | Q3 ARR 增长数据是否可持续，以及 Q2 增速放缓的原因尚未完全解释。 |
| CFO 明确表示公司将在 2027 年或更早上市。 | 人才流失（包括高管离职）对 OpenAI 长期创新能力的影响未知。 |
| OpenAI 已解散负责评估灾难性模型风险的 Preparedness 团队。 | IPO 时间表仍可能因市场或内部因素而改变。 |

**📖 主编点评**

OpenAI 加速 IPO 对你意味着 API 价格和产品策略可能更受资本市场驱动。你正在做 Agent 项目，依赖 OpenAI 的话，建议关注其企业版定价变化，并考虑多模型备份（如 Anthropic、DeepSeek）以降低风险。
