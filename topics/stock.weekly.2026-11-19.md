### 2. Anthropic IPO 定价每股 83 美元、估值 1.5 万亿美元，超预期区间上限

**[股票]** · ⭐⭐⭐⭐⭐ · _AP News_

Anthropic 的 IPO 最终定价每股 83 美元，完全稀释估值 1.5 万亿美元，高于此前 1.4 万亿的预期区间。S-1 文件里披露的季度人力成本 17 亿美元、人均月成本约 10.7 万美元，以及 9000 亿美元的 AI 支出承诺，让这场 IPO 同时是「增长故事」和「信用事件」。Michael Burry 和 Gary Marcus 都在公开唱空。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| Anthropic IPO 定价每股 83 美元，完全稀释估值 1.5 万亿美元，高于此前 1.4 万亿的预期 | 1.5 万亿美元估值对应的收入倍数是否可持续，要等首个公开季报才能验证 |
| S-1 披露季度人力成本 17 亿美元，约合每员工每月 10.7 万美元 | 9000 亿美元支出承诺里有多少是「take-or-pay」硬约束，S-1 未逐项拆解 |
| 公司披露 9000 亿美元的长期 AI 支出承诺 | 垃圾级评级意味着其债券融资成本将显著高于微软、谷歌，AI 军备竞赛的资本结构在分化 |
| 信用评级机构预计给予 Anthropic 高收益级（垃圾级）评级 | 「接近 RSI」的表述是法律免责还是真实技术判断，外界无法核实 |
| S-1 风险因素中写明公司可能「即将」接近递归自我改进（RSI） | 散户配售比例和首日换手率将决定这是「健康定价」还是「最后一棒」 |

**📖 主编点评**

如果你在简历或面试里聊 AI 行业，Anthropic 的 S-1 是本周最好的阅读材料——它把「AI 公司到底怎么花钱」摊开了。重点看两段：算力采购承诺的期限结构，以及收入确认口径里有多少是 API 预付费。这两点决定了你未来两年用 Claude API 时，价格是继续降还是被迫涨。
