### 5. 美联储开始担心 AI Agent 会触发银行挤兑

**[金融]** · ⭐⭐⭐⭐ · _pera_

美联储在一份讨论中提到，自主 AI Agent 若被用于批量执行提款或转账，可能在极短时间内形成挤兑压力。这是监管机构第一次把 Agent 的系统性风险摆上台面。对做 Agent 的人来说，这不只是金融新闻，是产品边界问题。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 美联储公开表达对 AI Agent 可能引发银行挤兑的担忧 | 目前是风险提示而非监管规则，落地形式未知 |
| 担忧的核心是 Agent 能自主、批量、高速执行金融操作 | Agent 触发挤兑的具体机制与阈值，材料未量化 |
| 该讨论出现在 2026 年 11 月中旬的公开材料中 | 是否会催生 Agent 金融操作的强制限速或人工确认要求，尚早 |

**📖 主编点评**

如果你以后给 Agent 接支付或账户类 MCP 工具，现在就该在设计里预留"人类确认闸门"和速率上限。监管一旦落地，没有这两层的能力会直接被卡死；提前做，反而能变成你项目里的一个卖点。
