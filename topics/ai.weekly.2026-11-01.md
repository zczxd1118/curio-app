### 5. Agent Skills 开发教程出现：WorkBuddy + Codex + DeepSeek Harness 的实战链路

**[AI]** · ⭐⭐⭐⭐ · _尚硅谷_

尚硅谷在 10 月 28 日发布 Agent Skills 开发教程，覆盖从 WorkBuddy、Codex 上手到项目落地的完整链路。这是中文社区里少数把 Skills 当作工程对象而非概念来教的内容，且发布时间在最近一周内。对你的 content-curator 来说，Skills 的组织方式直接决定子 Agent 的可维护性。

| ✅ 已确认 | ⚖️ 尚属判断 |
|---|---|
| 教程发布于 2026-10-28，覆盖 Agent Skills 从零到项目落地 | 尚硅谷系教程通常偏长且夹杂引流，实际工程密度需自行筛选 |
| 涉及 WorkBuddy、Codex、DeepSeek Harness 三个工具链 | Skills 目前缺乏统一规范，各家实现差异大，教程的可迁移性存疑 |
| 同期 B 站出现 DeepSeek Harness 与 Claude Code 的同任务对比实测 | DeepSeek Harness 的插件化设计是否优于 Claude Code，尚无中立评测 |
| Skills 已与 MCP 并列成为 Agent 工具生态的两条主线 | 这类教程的时效性很短，三个月后可能大半失效 |

**📖 主编点评**

你可以直接跳到教程里 Skills 的目录结构和加载机制那几节，跳过安装部分——你的 content-curator 已经有可用的 Agent 骨架，缺的是 Skills 的模块化拆分。重点看它怎么定义 Skill 的输入输出契约，这比看它怎么调 API 有价值得多。
